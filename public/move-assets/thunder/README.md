# Thunder bolt

`bolt.png` is a lightning-strike frame (a jagged bolt flashing through a
ghost-face flare) cropped from a ripped *Pokémon FireRed/LeafGreen*
battle-effects sheet ("Pokémon attack sprites ripped by wormintheworks. Made
By Nintendo... Please give credit for this if used in anything" —
www.gmhandbk.webs.com), with its solid green background chroma-keyed to
transparent. See `src/render/vfx/moves/thunderAttack.ts` for how it's loaded
and used — replaces the plain flash circle at the moment the bolt lands.
