# Leaf blade

`blade.png` is a small tumbling-leaf frame cropped from a ripped *Pokémon
FireRed/LeafGreen* battle-effects sheet ("Pokémon attack sprites ripped by
wormintheworks. Made By Nintendo... Please give credit for this if used in
anything" — www.gmhandbk.webs.com), with its solid green background
chroma-keyed to transparent. See `src/render/vfx/moves/leafAttack.ts` for how
it's loaded and used — replaces the procedural leaf particle.
