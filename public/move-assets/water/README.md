# Water pillar

`pillar.png` is one frame cropped from a twisted water-column animation in a
ripped *Pokémon FireRed/LeafGreen* battle-effects sheet ("Pokémon attack
sprites ripped by wormintheworks. Made By Nintendo... Please give credit for
this if used in anything" — www.gmhandbk.webs.com), with its solid green
background chroma-keyed to transparent. See
`src/render/vfx/moves/hydroPumpAttack.ts` for how it's loaded and used.
