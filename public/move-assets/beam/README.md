# Beam charge column

`column.png` is a glowing stacked-orb charge-up column cropped from a ripped
*Pokémon FireRed/LeafGreen* battle-effects sheet ("Pokémon attack sprites
ripped by wormintheworks. Made By Nintendo... Please give credit for this if
used in anything" — www.gmhandbk.webs.com), with its solid green background
chroma-keyed to transparent. Near-white/yellow so it takes a runtime tint
cleanly (see `src/render/vfx/moves/beamAttack.ts`), unlike `poison`/`water`'s
pre-colored, used-as-is convention — this is the first family asset that
actually gets tinted per move type.
