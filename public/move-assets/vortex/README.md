# Vortex twister

`twister.png` is a twisted grey tornado-column frame cropped from a ripped
*Pokémon FireRed/LeafGreen* battle-effects sheet ("Pokémon attack sprites
ripped by wormintheworks. Made By Nintendo... Please give credit for this if
used in anything" — www.gmhandbk.webs.com), with its solid green background
chroma-keyed to transparent. See `src/render/vfx/moves/vortexAttack.ts` for
how it's loaded and used — a real spinning-column flourish at the target,
alongside the existing procedural orbiting-arc rings.
